# sql_data_warehousing_socialmedia_project

# Social Media Usage & Wellness Analytics using SQL

## Project Overview
This project analyzes social media usage behavior and wellness indicators using SQL and data warehousing concepts.

The project focuses on extracting meaningful insights from demographic, engagement, and wellness-related data.

---

## Technologies Used
- SQL
- MySQL
- Data Warehousing Concepts
- GitHub
- Microsoft word
- Kaggle dataset(social media)

---

## Key Insights
- Age vs Active Time
- Gender vs Active Time
- Urban vs Rural Usage
- Most Active Country
- BMI vs Screen Time
- Content Preference vs Engagement
- Notification Fatigue Analysis
- Sleep vs Stress Analysis
- Wellness Score
- Social Engagement Score

---

## SQL Concepts Used
- SELECT
- GROUP BY
- ORDER BY
- Aggregate Functions
- Joins
- Subqueries

---

## Challenges Faced
The main issue encountered during the project was MySQL Safe Update Mode.
Solution - setting safe update mode as 0 temporarily.

---

## Project Outcome
Built a structured SQL data warehouse with cleansed and validated data for business analysis.
